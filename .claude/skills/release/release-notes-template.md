## 安装

1. 下载下方的 `Immerse-<版本号>.dmg`（macOS 14+，Apple 芯片 / Intel 通用）
2. 打开 DMG，把 `Immerse` 拖进「应用程序」
3. 首次打开：App 未经 Apple 公证，会被系统拦下，需要放行一次：
   - **macOS 15 及以上**：先双击一次 → 打开「系统设置 → 隐私与安全性」，滚到底部点「仍要打开」→ 再点「打开」
   - **macOS 14**：在「应用程序」里右键 Immerse → 打开 → 打开

如果提示「已损坏，无法打开」，在终端执行：

```bash
xattr -dr com.apple.quarantine /Applications/Immerse.app
```

使用说明见 [README](https://github.com/debugzhao/Immerse#readme)。
