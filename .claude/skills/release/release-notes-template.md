## Installation

1. Download `Immerse-<version>.dmg` below (macOS 14+, universal build for Apple silicon and Intel)
2. Open the DMG and drag `Immerse` into `Applications`
3. First launch: Immerse is not notarized by Apple, so macOS blocks it the first time. Allow it once:
   - **macOS 15 and later**: double-click Immerse once → open **System Settings → Privacy & Security**, scroll to the bottom and click **Open Anyway** → click **Open**
   - **macOS 14**: in `Applications`, right-click Immerse → **Open** → **Open**

If macOS says the app "is damaged and can't be opened", run this once in Terminal:

```bash
xattr -dr com.apple.quarantine /Applications/Immerse.app
```

See the [README](https://github.com/debugzhao/Immerse/blob/main/README.en.md) for usage.
